# 数据分析看板

`analytics-dashboard-demo` 是一个无后端、无远程资源的 React + TypeScript 合成演示案例，视觉目标为 PromptForge 数据分析看板参考图。源码按多文件项目拆分为 `components/`、`data/`、`hooks/`、`pages/`、`types/` 和 `utils/`，保留 `source/index.tsx`、`source/App.tsx` 与 `source/styles.css` 作为入口。

左侧“数据分析”导航现已具备完整的页内页面切换，不再只是切换高亮或 Toast：

- 总览看板：六项核心指标、可交互业务趋势、渠道来源、行业分布与客户明细。
- 业务数据：收入/订单/客户指标、业务趋势、业务线结构、目标完成度与明细表。
- 用户分析：活跃与新增用户、用户增长趋势、行为偏好、行业画像与留存分群。
- 产品分析：产品活跃、API 调用、功能渗透、产品卡片切换、产品趋势与功能使用排行。
- 渠道分析：渠道触达、来源分布、渠道贡献占比与获客效率明细。
- 财务分析：收入、客单价、毛利率、成本结构、现金流与经营摘要。
- 自定义报表：报表名称、模块勾选、快速模板、预览生成与本地 CSV 导出。

日期范围支持 7/30/90 天以及显式空数据演示，并会同步驱动各分析页的指标、图表与明细。客户表继续支持名称/联系人/行业关键词搜索、活跃/沉睡状态筛选、行业筛选、清除筛选、金额/日期排序、勾选、分页、页容量切换、详情抽屉以及当前筛选结果的本地 CSV 导出。

所有数据均为本地固定合成数据；不连接后端、数据库、远程图片、远程字体或外部服务。窄屏时桌面侧栏会收起，并提供可横向滚动的移动端页面导航；表格仅在自身容器中横向滚动，避免页面级严重横向溢出。
