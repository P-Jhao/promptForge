# 首页视觉刷新

## 目标

将 PromptForge 首页调整为参考图中的中文 SaaS 产品落地页：以浅蓝白渐变为底，突出“从一个想法，到可交互的前端原型”的首屏信息，并补齐流程、案例、用户反馈、CTA 与页脚等完整营销结构。

## 实施范围

- 只调整首页展示层，不改变工作台、案例数据和生成接口。
- 首屏产品预览使用前端 CSS/HTML 构造，避免引入不可控的外部资源。
- 保留 `/workspace`、客户管理、数据分析和博客案例入口。
- 需要覆盖桌面端与窄屏布局，并在构建后进行浏览器验证。

## 验收重点

- 顶部导航、首屏文案、产品 mockup、技术栈说明与参考图的层次关系一致。
- 三步流程、真实案例、用户评价、渐变 CTA 和页脚完整可见。
- 首页链接仍能进入现有工作台和案例页面。
- `pnpm lint` 与 `pnpm build` 通过。
