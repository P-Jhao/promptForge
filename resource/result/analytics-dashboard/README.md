# 数据分析看板

`analytics-dashboard-demo` 是一个无后端、无远程资源的 React + TypeScript 合成演示案例，视觉目标为 PromptForge 数据分析看板参考图。源码按多文件项目拆分为 `components/`、`data/`、`hooks/`、`pages/`、`types/` 和 `utils/`，保留 `source/index.tsx`、`source/App.tsx` 与 `source/styles.css` 作为入口。

本版不仅补齐了“数据分析”左侧导航的七个分析页面，也补齐了顶部主导航和账户菜单：

- 数据分析：保留总览看板、业务数据、用户分析、产品分析、渠道分析、财务分析、自定义报表七个页面。
- 客户管理：客户统计、关键词搜索、状态筛选、清除筛选、本地新增客户、客户列表与分页。
- 产品中心：产品目录、产品选择、启用/停用、配置反馈、使用规模与当前产品详情。
- 团队协作：成员概览、任务筛选、任务状态推进和本地邀请反馈。
- 账户信息：可编辑姓名、企业/工作区、职位，并提供本地保存反馈和套餐信息。
- 偏好设置：邮件通知、每周报告、自动刷新和界面密度设置，均具有真实的本地状态变化。
- 全局搜索：会根据客户、产品、团队、账户、偏好等关键词跳转到对应工作区页面。

数据分析区域继续支持 7/30/90 天以及显式空数据演示，并会同步驱动各分析页的指标、图表与明细。客户表继续支持名称/联系人/行业关键词搜索、活跃/沉睡状态筛选、行业筛选、清除筛选、金额/日期排序、勾选、分页、页容量切换、详情抽屉以及当前筛选结果的本地 CSV 导出。

所有数据均为本地固定合成数据；不连接后端、数据库、远程图片、远程字体或外部服务。窄屏时新增移动端主导航，分析侧栏会收起并提供可横向滚动的分析页面导航；表格仅在自身容器中横向滚动，避免页面级严重横向溢出。
