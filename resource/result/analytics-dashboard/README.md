# 数据分析看板

`analytics-dashboard-demo` 是一个无后端、无远程资源的 React + TypeScript 合成演示案例，视觉目标为 PromptForge 数据分析看板参考图。源码已按多文件项目拆分为 `components/`、`data/`、`hooks/`、`types/` 和 `utils/`，保留 `source/index.tsx`、`source/App.tsx` 与 `source/styles.css` 作为入口。

默认“过去 30 天”视图包含六项核心指标、可交互业务趋势、渠道来源、客户行业分布和客户明细。日期范围支持 7/30/90 天以及显式空数据演示，切换范围会同步更新指标、趋势、图表和表格日期数据。客户表支持名称/联系人/行业关键词搜索、活跃/沉睡状态筛选、行业筛选、清除筛选、金额/日期排序、勾选、分页、页容量切换、详情抽屉以及当前筛选结果的本地 CSV 导出。

所有数据均为本地固定合成数据；不连接后端、数据库、远程图片、远程字体或外部服务。窄屏布局会收起侧栏并重排卡片和图表，表格仅在自身容器中横向滚动，避免页面级严重横向溢出。
