# 客户管理后台

`customer-management-demo` 是一个 React + TypeScript 的多模块客户管理演示案例。客户管理页按参考图保留顶部栏、左侧导航、统计卡、筛选工具栏、客户表格、分页与右侧详情抽屉；本次补齐了左侧导航对应的工作台、销售机会、跟进记录、合同管理、产品管理、数据报表、团队协作和系统设置页面，因此切换导航不会再出现空页面。

所有客户、联系人、成员、商机、合同、产品和跟进内容均为合成演示数据，不对应真实自然人或真实商务关系。预览不调用后端、数据库、模型接口或远程资源；新增、编辑、筛选、状态切换、导出报表等操作只发生在当前浏览器会话内，刷新或使用右上角“重置演示数据”会恢复固定数据。

核心源码位于 `source/`，拆分为 `components/`、`data/`、`hooks/`、`pages/`、`types/`、`utils/` 与 `styles/`。`generatedFiles.ts` 已按当前 `source/` 的 37 个文件重新生成，用于宿主工作台装配 Sandpack 文件。
