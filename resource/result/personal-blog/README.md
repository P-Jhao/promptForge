# 清川的博客

`personal-blog-demo` 是一个 React + TypeScript 的纯前端个人博客演示。文章、作者、日期与统计数字均为虚构内容，不连接 CMS、数据库、发布后端或外部资源。

本次界面以提供的博客参考图为视觉目标，源码拆分为组件、数据、hooks、types 与 utils。首页包含精选文章、作者卡片、最新文章、分类筛选、热门标签、订阅区域与专栏入口；文章详情页保留统一的排版与明暗主题。

可交互功能包括：标题/摘要/分类/标签搜索、产品/技术/生活/思考分类筛选、标签筛选与清除、文章详情与返回、主题切换、订阅/取消订阅、关注/取消关注、导航滚动反馈、空结果状态和移动端响应式布局。页面中的插图和图标全部由 CSS 与内联 SVG 绘制，不使用远程图片、远程字体或新增 npm 依赖。
